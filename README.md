# wb-helper · WorkBuddy 每日领取云端自动化

给**一个账号**做 WorkBuddy 每日自动领取：签到、打卡、猫猫旅行（派出/领取）、奖励只读查询。
本机负责取凭证，云端沙盒负责每天自动跑，凭证经资料库跨实例持久化。

**版本** 1.8.4 ｜ **变体** local-hardened ｜ **git 分支** main ｜ **不含任何凭证**

---

## 快速开始

### 方式一：让 WorkBuddy 自己装（推荐）

**第 1 步** · 复制本仓库地址

```
https://github.com/ruilin365/WorkBuddy-helper
```

**第 2 步** · 在**桌面端 WorkBuddy** 新建一个会话，把下面这段整句粘进去发送：

```
请阅读 https://github.com/ruilin365/WorkBuddy-helper 仓库里的 DEPLOY.md，严格按其中
「一、装 skill → 二、取凭证 → 三、打包上传资料库 → 四、云端建任务」的顺序，在这台电脑上
从零部署 wb-helper。每一步执行完把结果告我，遇到报错就原样贴出来并停下，不要自行换方案、
不要跳过步骤、不要凭猜测操作。
```

它会先读文档，再按章节执行。**注意：执行到第二章「取凭证」时，它会关闭并重开 WorkBuddy，
请先保存所有未保存的工作。**

**第 3 步** · 等它把准备工作做完（装好 skill、取到凭证、上传 3 个文件到你的资料库），
它会交给你**一段定时任务提示词**。

**第 4 步** · 打开**手机 App 或小程序**，进「云端工作」→ 新建定时任务 →「自定义添加」，
把那段提示词粘贴进去，时间设成 **每天 05:00 和 13:00**（两个任务用同一份提示词）。

> 云端目前只能在手机 App / 小程序里操作，桌面端没有入口。

**第 5 步** · 别等第二天。在云端会话里点一下测试执行按钮看效果。


回报里出现「签到/打卡/猫猫」三项就说明通了。

## 给 WorkBuddy 看的（Agent 执行须知）

> 你如果是一个被要求「按这个仓库部署 wb-helper」的 WorkBuddy 桌面端 Agent，先读完本节再动手。

1. **先完整读 [DEPLOY.md](DEPLOY.md)**，它是唯一权威流程。本章只是摘要与红线，不能替代它。
2. **按章节顺序执行**，一章做完确认结果再做下一章。不要并行、不要跳章。
3. **第二章取凭证会重启 WorkBuddy**，执行前必须先提醒用户保存工作，等用户确认后再继续。
4. **第三章上传资料库时，3 个文件必须当 `.txt` 原样上传**，文件名（含版本号）一个字都不能改。
   传成在线文档云端就下不回来。
5. **报错就停**。原样贴出错误并说明停在哪一步。不要自行替换下载地址、不要从第三方源安装、
   不要绕过校验、不要「试着改一下脚本」。
6. **不碰写操作以外的东西**：这个 skill 只领取，禁止调用任何兑换、抽奖、补签接口。
7. 全部做完后，把 DEPLOY.md 第四章里那段**定时任务提示词**原文交给用户，并告诉他在手机 App／
   小程序的「云端工作」里建 05:00 与 13:00 两个任务（两个任务同一份提示词，不要建多个）。

## 仓库里有什么

| 路径 | 说明 |
|---|---|
| `bootstrap_bundle.sh` | **云端入口**。一行 curl 即装。从资料库取最新 bundle 并解包到 `~/.workbuddy/skills/wb-helper` |
| `scripts/` | 全部脚本（签到四分支、凭证链路、资料库同步、完整性自检） |
| `SKILL.md` | 完整手册：原理、踩坑记录、沙盒实测结论、排错 |
| `DEPLOY.md` | 部署与复现手册，四章从零到通 |
| `_meta.json` | 变体元信息与版本号 |

## 仓库里没有什么（有意为之）

`config/`（token、refresh_token、user_id、凭证文件）、`logs/`、`dist/`（打包产物）全部在 `.gitignore`。
**凭证永不上仓库**——它只走「本机 → 资料库个人空间 → 云端沙盒」这条链路。

## 设计约束（改代码前先读）

- 只领取，**不兑换**：奖励、抽奖、补签一律不碰，检测到可兑换只上报。
- 无联网安装语义：安装只从**你自己的资料库**取包，校验 sha256 后才解包，不从任何第三方地址拉代码。
- 云端沙盒是一次性容器：每次都假设「什么都没有」，脚本必须无状态、可重复执行。
- 凭证失效有两种形态，处置完全不同（会话被服务端销毁 vs refresh_token 过期），见 SKILL.md §十二。

## 一句话架构

```
本机 WorkBuddy 登录态
   └─[取凭证]→ config/ ─[上传]→ 资料库个人空间 ─[沙盒读取]→ 云端定时任务
                                    ↑                        │
                                    └──[续期后回写]───────────┘
```
